How to use this map

This is a big-picture atlas of the durable foundations of software engineering — the languages, data structures, algorithms, computer architecture, operating systems, networking, databases, distributed systems, software design, security, testing, performance and engineering practice that sit beneath every specialization. It is meant to be tool-agnostic and broadly applicable — the concepts that stay true whether you build full-stack web apps, AI/ML systems, mobile or desktop apps, or low-level systems, as frameworks come and go. The goal is to see the whole territory at once and mark what you know vs. what you don't. For the concrete, role-specific stacks, see the sibling Full-Stack Developer and AI / ML maps.

  • Mark familiarity on any topic — Unknown, Learning, Known. The map lights up as you go; your progress is saved in this browser.
  • Map view — the full landscape as a radial graph. Each colored sector is a domain; rings go domain → subdomain → topic. Drag to pan, scroll to zoom, hover to trace prerequisite/related links, click for detail.
  • Outline view — the same knowledge as a checklist with progress bars, ideal for quickly marking areas you already command (use the per-section bulk buttons).
  • Relationships — arrows point from a prerequisite to what it enables; dashed lines mark closely related topics. Use them to find the on-ramp into something unfamiliar.
  • Export / Import your progress as JSON to back it up or move browsers.
